🎯 FORMULA REKOMENDASI (Similarity Scoring)
═══════════════════════════════════════════════════════════════

Sim(u,m) = 0.25 × (S_harga + S_cc + S_fuel + S_kursi)

Component:
- S_harga  = 1 - |harga_mobil - preferensi_harga| / max_harga
- S_cc     = 1 - |cc_mobil - preferensi_cc| / max_cc
- S_fuel   = 1 (match) atau 0 (tidak match)
- S_kursi  = 1 - |kursi_mobil - preferensi_kursi| / max_kursi

Output: Score 0.0 - 1.0 (0% - 100%)

🔍 DEBUGGING TIPS

Problem: Form tidak tersubmit

→ Check: Apakah action="{{ route('rekomendasi') }}" benar?

Problem: Hasil tidak muncul
→ Check: Apakah data di database ada?
→ Check: Apakah data lolos filtering?

Problem: Skor tidak akurat
→ Check: Database values max_harga, max_cc, max_kursi
→ Check: Pastikan harga, cc, kursi adalah numeric
→ Manual: Calculate 1-2 items untuk validasi formula

Problem: 500 Server Error
→ Check: Apakah semua model attributes ada?
→ Check: Storage/logs untuk error message
→ Try: Jalankan `php artisan optimize`
